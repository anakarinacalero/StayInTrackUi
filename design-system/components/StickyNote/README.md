# StickyNote

Post-it notes with tape or a pin, written in the handwriting face.

- Props: `color` ('butter' | 'rose' | 'sky' | 'sage'), `rotate` (deg, keep between -4 and 4), `pin` ('tape' | 'pin' | 'none'), children.
- Used for caught wishes and quick notes. Vary rotation and color across a board; never two identical neighbours.
- Text is always `on-sticky`.

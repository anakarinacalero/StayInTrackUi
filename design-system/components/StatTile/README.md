# StatTile

A single number with its label: the form for "how many" answers.

- Props: `label` (sentence case, no colon), `value`, `unit`, `note` (what it is out of, or a comparison), `icon`, `tone` ('paper' | 'sage' | 'rose' | 'butter').
- Values use Hind semibold, not the display face. One hero tile per screen; the rest are supporting.

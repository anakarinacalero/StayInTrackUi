# TextField

Rounded, ink-outlined fields like the boxes on the printed tracker sheet.

- Props: `label`, `hint`, `script` (handwriting face for what the user writes in their journal), `multiline`, plus native input props.
- Use `script` for journal content (habit names, wishes, reasons); plain for account data (email, password).
- Labels are uppercase `label` style in `ink-muted`; never put the label only in the placeholder.

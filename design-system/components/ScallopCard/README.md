# ScallopCard

A card with a scalloped edge all the way round, after the Happy Planner scalloped notebooks.

- Props: `tone` ('paper' | 'blush' | 'butter' | 'cover'), children, `style`, `className`.
- Use for small summary tiles and shortcuts (Home), never for long forms (use `JournalPage`).
- Text: `ink` on paper and blush, `on-sticky` on butter, `ivory` on cover.

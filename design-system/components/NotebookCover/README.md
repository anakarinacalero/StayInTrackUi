# NotebookCover

The black notebook cover with ivory polka dots, after the Happy Planner black-and-ivory dot covers.

- Use it once per screen at most: the login's left panel, or a footer band.
- Text on it is `ivory`; accents are `gold`. Put the logo inside a `.sit-cover-plate` (a solid `cover` plate framed in `gold`) so dots never run behind text.
- Props: children, `style`, `className`. The consumer sets its size and radius.

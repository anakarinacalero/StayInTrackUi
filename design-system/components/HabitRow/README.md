# HabitRow

One day of the *minimal tracker*: day circle, dotted leader and a bar split into min | ok | ideal by dashed lines.

- Props: `day`, `value` (0 none, 1 min, 2 ok, 3 ideal), `onChange(value)`, `labels`.
- Click a segment to fill up to it; click the filled end again to step back. The level name is written at the end of the row.
- Seven rows make a week. Put the min / ok / ideal targets above the bar column.

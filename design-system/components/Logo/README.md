# Logo

The StayInTrack mark: a six-petal doodle flower beside the Sniglet wordmark, with *in* set in `rose`.

- Use `size="sm"` in the nav bar, `md` in cards, `lg` on the login cover only.
- On the black notebook cover pass `onCover`: the word turns `ivory`, the flower and *in* turn `gold` like foil stamping.
- Never recolor the flower outside `mustard` (paper) or `gold` (cover); never set the wordmark in another face.
- Props: `size` ('sm' | 'md' | 'lg'), `onCover` (boolean). No children.

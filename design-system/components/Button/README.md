# Button

Pill buttons. **Primary** (ink fill) at most once per view, for the main action.

- Props: `variant` ('primary' | 'secondary' | 'soft' | 'ghost'), `size` ('sm' | 'md' | 'lg'), any native button prop, children.
- `soft` (blush) is the friendly in-tool action: Catch it, Add habit. `ghost` is a teal text link for secondary routes.
- Labels: verb first, sentence case, two or three words.

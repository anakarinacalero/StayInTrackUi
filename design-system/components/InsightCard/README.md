# InsightCard

A finding from the helper, written as one plain sentence on a sticky-note color with an icon.

- Props: `icon` (Doodle kind: bulb, phone, sprout, calendar, target, chart, sparkle), `tone` ('butter' | 'rose' | 'sky' | 'sage'), `title` (the finding, about 60 characters at most), children (one supporting sentence), `action` (a button).
- Tone by meaning: `rose` for a problem pattern, `sage` for something working, `butter` for a neutral observation, `sky` for a question to the user.
- Lead every insight screen with one; never stack more than three.
